\# Quizzo AI – Live Quiz Application



A real-time multiplayer quiz application built with the MERN stack and powered by Google Gemini AI.

\## ✨ Features



\- User Authentication (Login / Register)

\- Create quizzes using \*\*Google Gemini AI\*\*

&nbsp; - Based on Topic or Book

&nbsp; - Choose difficulty, number of questions, and time per question

&nbsp; - Schedule start date \& time

\- Automatic quiz start using cron jobs

\- Real-time Waiting Room

\- Live multiplayer quiz with Socket.io

\- Dashboard with quiz history and performance

\- Light / Dark mode
